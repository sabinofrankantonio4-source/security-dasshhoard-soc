
# 🛡️ Security Dashboard SOC

Dashboard SOC para gestión de incidentes - Detección SSH no autorizado, Asset Inventory, Endpoint Manager - Hecho con Amazon Q Apps.

**🔴 Live Demo:** Pega aquí tu link de `quick.aws.com`

### 🚨 Funcionalidades
- Gestión de incidentes (Abierto / En progreso / Resuelto)
- Severidad CRÍTICO, MEDIUM, LOW
- Caso real: `INC-001 Unauthorized SSH Access Detected`
- Módulos: Asset Inventory + Endpoint Manager
- Asistente en tiempo real para respuesta

### 🛠️ Por qué hice este proyecto
Para demostrar habilidades de SOC Analyst / GRC: triage de alertas, priorización de incidentes y documentación para ISO 27001.
